# 微信翻译克星

> 把中文变成程序、表情、或隐形墨水 —— 微信自带的翻译翻不出来。

和 [KongEr 生成器](../) 是同门师兄弟：那个把中文变成英文谐音，这个把中文变成**机翻看不懂的东西**。

## 五种玩法

| 方式 | 效果 | 点评 |
| --- | --- | --- |
| **Python 源码** | `print("".join(chr(c) for c in [20320,36825,...]))` | 字面意义上的「把中文翻译成程序」，最短 |
| **表情包** | 每个字节变成两个表情 | 手机上看着最热闹 |
| **Base64** | 一串字母数字 | 最通用，但他一解码就开 |
| **脑力操 Brainfuck** | 纯加减括号符号 | 最像程序，缺点是长 |
| **隐形墨水** | 零宽字符 | 看起来是条空消息 |

## 用法

双击 `index.html`，输入中文 → 选方式 → 加密 → 复制 → 粘进微信。

输入框下方还有**逐字对照**，能看每个字变成了什么。

**在线版**：https://leerolling.github.io/KongEr/wechat-cipher/

## 它挡不住什么

- **挡不住 AI。** 把结果粘给任意大模型基本秒破。这是**编码游戏**，不是加密。
- 「隐形墨水」用的是零宽字符，微信可能过滤或显示异常，发之前先给自己发一条试试。
